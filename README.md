Task 6: Palindrome Checker in Java

Description

The Palindrome Checker is a Java program that checks whether a given string or number reads the same forward and backward.

It also supports case-insensitive string checking by converting uppercase letters to lowercase before comparison.

Objective

- Practice Java strings and loops.
- Understand character manipulation.
- Learn to use conditions.
- Understand the "StringBuilder" class.
- Check both string and number palindromes.

Technologies Used

- Java
- Scanner class
- String class
- StringBuilder class
- Conditional statements

How It Works

1. The program accepts a word or number from the user.
2. It converts the input to lowercase to support case-insensitive checking.
3. It reverses the input using "StringBuilder".
4. It compares the original input with the reversed input.
5. If both are equal, it displays that the input is a palindrome. Otherwise, it displays that it is not a palindrome.

Sample Output

Example 1: Palindrome String

Enter a word or number: Madam
madam is a palindrome.

Example 2: Palindrome Number

Enter a word or number: 121
121 is a palindrome.

Example 3: Not a Palindrome

Enter a word or number: hello
hello is not a palindrome.

Concepts Learned

- Taking input using "Scanner"
- Working with Java strings
- Converting strings to lowercase
- Reversing strings using "StringBuilder"
- Comparing strings using "equals()"
- Using "if-else" conditions

Conclusion
